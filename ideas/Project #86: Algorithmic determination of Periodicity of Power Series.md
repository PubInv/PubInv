# Project #86: Algorithmic determination of Periodicity of Power Series

It is possible the answer to thid problem of pure mathematical analysis is known, but as can be seen 
by this conversation at Math Stack Exchange: 
[https://math.stackexchange.com/questions/2593137/is-there-an-algorithm-to-determine-if-a-power-series-is-periodic](https://math.stackexchange.com/questions/2593137/is-there-an-algorithm-to-determine-if-a-power-series-is-periodic)

...it is a bit murky.

This project is to clearly define what the question is asking and then attempt to clarify the answer.
At the time of this writing this is a WIP.

# Attempting to clarify the quesition

If we were given a finite, closed form expression of a power series, that can be expressed in n
bytes for example in suitable language like LISP or some variant of LaTeX or Mathematica's language,
is there an algorithm can determine if this series is periodic?

If there is not, can we produce criteria which allow use to algorithmically proof that it is 
not periodic, for example?
