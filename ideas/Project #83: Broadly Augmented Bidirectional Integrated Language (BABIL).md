# Broadly Augmented Bidirectional Integrated Language (BABIL)
By John LaRocco
## Summary
In today’s interconnected world, people from all backgrounds interact with one another and
require a reliable and accurate way to communicate despite existing language barriers. Language
learning and comprehension is a difficult task that many endure and people need a way to
comprehend other languages in an accurate, fast, efficient, and comfortable manner. Broadly
Augmented Bidirectional Integrated Language (BABIL) aims to tackle this problem and provide
a solution that fits the needs of the stakeholders while staying within the constraints of the real
world. The sponsor and primary stakeholder is looking for an autonomous wearable language
translator to help bridge communication gaps for the end users. This device should receive
speech in various languages and translate via subtitles on a display to the wearer&#39;s choice of
language. The unit should be compact and not create discomfort. This device&#39;s target users are
those who are hard of hearing, travelers, language learners, and those away from reliable
connections. Solving this problem will help to break down language barriers with convenience in
mind. 
## Background
Some constraints that must be addressed with this solution is the distractibility of the device for
safety purposes, condensing the necessary hardware and software into one standalone device,
and the budget/cost of the device. The software that is used for the speech-to-text processing
does have some standards that can be followed and tested, this includes ISO/IEC 30122-2:2017,
which had criteria and testing for speech-to-text engines. Additionally, ISO 17100 defines
standards for translation services and processes. These standards can be used to test the software
implementation of the project and ensure that the software fulfills the requirements set by these
standards. The design will be tested via predetermined criteria such as; distance at where the
speech can be picked up and translated, the speed of translation and subtitle output, battery life,
and overall comfort.
## Need
By analyzing the project’s needs, existing resources, and the current market, some design
concepts can be brainstormed and a better understanding of where this project stands can be
defined. When analyzing the current market, there are several products and services that fulfill
certain aspects of the project’s needs. The current market for translation services is dominated by
cloud-based translation mediums that are accessed through the web or mobile apps. These
applications are typically free, fast, and very accurate. In addition to these applications, there are
portable handheld translation devices that have the same function but are not as fast or accurate
as cloud translation. From here one can see that there are ways for translation to be
accomplished, but these solutions are often reliant on internet connections, rely on patented
technology, or have higher prices. BABIL must met the need for an augmented reality, open-
source wearable design with runs locally.
